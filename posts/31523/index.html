零假设挑战

追求聪明的人，试图让AI帮自己写出完美的文章、做出稳赚不赔的投资策略；而避免愚蠢的人，使用AI来寻找自己逻辑链条中的断裂处、拓展思考的盲区，并时刻保持对真相的最终把控权。

AI误区解决

  1. Chain-of-Thought（CoT，让我们一步一步想）
  2. Tree-of-Thoughts（ToT，树状思考） / ReAct（边想边行动） / Graph Prompting
  3. DSPy / Automatic Prompt Engineer（APE，自动工程师）
  4. rompt Chaining（链式提示） + Role Prompting（角色扮演） + Few-shot（给例子）
  5. Hybrid（CoT + Meta + DSPy）

  7. 反向提示。
